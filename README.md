# Aircraft Detection Using YOLO

A computer vision project that uses YOLO to detect aircraft in images.

## Overview

This project explores object detection using a YOLO-based computer vision workflow. The goal is to train and evaluate a model that can identify aircraft in images.

## What I Did

- Prepared and organized image data for object detection
- Configured a YOLO model for aircraft detection
- Trained the model on the prepared dataset
- Evaluated the model's detection results
- Analyzed model performance using visualizations
- Built an application to interact with the trained model

## Technologies

- Python
- YOLO
- Computer Vision
- Deep Learning
- Object Detection
- Streamlit
